# Documentação do TFT Viewer

Esta pasta reúne a documentação que estava na pasta histórica `viwer/`, além da referência principal do visualizador.

- `TFT_VIEWER_PLAN.md`: requisitos, arquitetura, layout, controles, logs, inferência, replay e critérios de aceite.
- `README.md`: contexto dos diagramas e wireframes.
- `architecture.svg`: arquitetura PPO/controlador/engine/replay/interface.
- `dashboard-wireframe.svg`: oito jogadores com tabuleiros completos 7×4.
- `combat-view.svg`: wireframe da visão de combate.
- `event-lifecycle.svg`: ciclo de auditoria de uma decisão.

A implementação está no pacote Python `viewer/`. Esta pasta contém somente documentação e artefatos visuais.
