# Documentação do TFT Viewer

Esta pasta contém a especificação completa e os assets de planejamento do visualizador.

- `TFT_VIEWER_PLAN.md`: fonte única de requisitos, arquitetura, interface, eventos, inferência, replay e critérios de aceite.
- `architecture.svg`: arquitetura entre PPO, controlador, engine, replay e interface.
- `dashboard-wireframe.svg`: oito jogadores, cada um com tabuleiro completo 7×4.
- `combat-view.svg`: visão detalhada de combate.
- `event-lifecycle.svg`: ciclo de auditoria de uma decisão.

O aplicativo executável fica em `viewer/`; esta pasta é apenas documentação e recursos visuais. Não marcar requisitos como validados sem testes executados.
